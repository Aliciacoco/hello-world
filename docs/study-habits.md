# 晨学与早睡打卡

入口：导航「打卡」→ `/checkin`。默认只展示今天的晨学、小结与睡前状态；历史记录、提醒设置和记录修改按需展开。

- 北京时间周一至周五 06:00–07:00 学习，按实际学习时长手动确认；满 60 分钟并填写小结后可以完成晨学打卡。支持补学、补记，周末自由安排。
- 小结可以先存草稿，完成打卡后仍可修改；历史记录按日期查看。本周显示周一至周五的完成情况。
- 每天洗漱完毕、准备上床时独立打卡，目标 22:00 前。默认记录当前北京时间，也可填写实际就寝时间补记。记录的是上床时间。
- 学习时长由用户自行记录，不会根据网页打开时长自动计算。
- 旧的积分目标、积分打卡日历与自动统计接口已移除。答题获得积分和积分兑换仍正常使用。

## 手机提醒

在打卡页展开「提醒设置」，点击「开启学习与早睡提醒」，允许浏览器通知。每台设备分别开启或关闭。

- 周一至周五 05:55：提醒 06:00 开始学习。
- 每天 21:30：提醒开始洗漱，22:00 前上床。
- 点击通知打开 `/checkin`。可用「测试通知」检查权限与设备设置。
- 使用既有 Web Push 推送通道，提醒与消费积分通知可同时订阅、分别关闭。关闭其中一种不取消浏览器的共享推送订阅。
- iPhone 从 Safari「添加到主屏幕」，再从主屏幕打开 HTTPS 网站开启。真实手机投递与通知展示仍需部署后验证。
- 每个时段分别保存发送日期，服务器重启后不重复投递；失败后 15 分钟重试，超过计划时间 30 分钟不再补发。

## 数据与部署

`DATA_DIR/study_habits.json` 保存按日期索引的学习完成状态、分钟数、小结、就寝时间与更新时间。通过临时文件后重命名保存，文件损坏时返回错误，不覆盖旧数据。文件及其 `.tmp` 均已加入 `.gitignore`。

沿用现有部署流程，新增后端 `study-habits.js` 必须随 `server/` 同步。提醒发送记录仍存于现有 `mobile_reminders.json`，备份时包含这两个运行时文件。

接口：`GET /api/habits` 读取日期与全部记录；`PUT /api/habits/:date` 保存指定日期。未来日期、非法日期与时长、小结超长均返回 400。

验证：

```powershell
node --test server/mobile-reminders.test.js server/study-habits.test.js
npm run build
```
